- Built `GeneralsXZH.exe` (7.4MB) from source via the `win32-vcpkg` preset (NGMP=ON) with Visual Studio 2026 and a fully offline vcpkg instance.
- Solved dependency downloads without a VPN by prefetching the 8 remaining vcpkg files through Chinese GitHub mirror proxies (`gh-proxy.com` etc.) with SHA-512 verification; the local VPN only accelerates `github.com` and throttles the `release-assets`/`codeload` CDNs.
- Fixed two build blockers: replaced the missing MFC `afxres.h` with the Windows SDK `winres.h` in both `RTS.RC` files (backported to Generals), and disabled `RTS_BUILD_OPTION_SAGE_PATCH` (requires SDL3).
- Shipped a self-contained run directory `dist\` (exe + 9 vcpkg DLLs + mss32/Bink + VC runtime) and `launch.ps1` which mounts the retail Chinese data via `CNC_GENERALS_ZH_PATH` / `CNC_GENERALS_PATH`.
- Root-caused a runtime "Technical Difficulties" crash: `Win32BIGFileSystem` builds its `FindFirstFile` mask by concatenating the directory with `*.big`, so the env paths MUST end with a backslash or nothing matches.
- Root-caused magenta textures on double-click launches: the base Generals asset fallback resolves `../Generals` but the user's folder is `Command and Conquer Generals`; provided an `Options.ini` with `[Paths] AssetPath/GeneralsAssetPath` as the fix.
- User verified all acceptance items: Chinese fonts, no magenta textures, audio, and skirmish play with working unit production. First milestone reached.
